# InnoBuilders Consulting — Briefing Interativo & Diagnóstico Estratégico

Aplicação executiva desenvolvida pela **487 Digital** para levantamento estratégico, técnico e visual do novo portal corporativo da **InnoBuilders Consulting**.

## Recursos
- 30 Questões Estratégicas divididas em 6 Fases (Posicionamento, ICP, UX/Arquitetura, Conteúdo, Conversão e Infraestrutura).
- Design System Apple Human Interface Guidelines (Liquid Glass, Obsidian Dark & Electric Teal).
- Autosave contínuo em localStorage com proteção contra perda de dados.
- Exportação nativa de Resumo Executivo em Markdown, PDF para Impressão e JSON Estruturado.
